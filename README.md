# CodeAlpha Data Analytics Internship - Task 4: Sentiment Analysis

## Overview
This project performs customer sentiment analysis on the Amazon Sales dataset using Python and Natural Language Processing (NLP) with the VADER lexicon. Reviews are classified into Positive, Neutral, and Negative sentiments to extract customer satisfaction trends.

## Tools & Libraries
- Python
- Pandas
- NLTK (VADER)
- Matplotlib & Seaborn
- WordCloud

## Results Summary
- **Positive Reviews:** 1,380
- **Negative Reviews:** 74
- **Neutral Reviews:** 11

## Visualizations
- Sentiment Distribution: `sentiment_distribution.png`
- Positive & Negative Word Clouds: `wordclouds.png`

## Key Insights
- The overall sentiment is overwhelmingly positive (>94%), reflecting satisfaction with product utility and performance.
- Negative feedback centers around build quality, durability issues, and defective components.
